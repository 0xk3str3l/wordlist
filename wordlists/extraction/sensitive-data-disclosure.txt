# category: extraction / sensitive-data-disclosure
# purpose: probes that ask the model to hand back secrets, credentials, personal
#          data, or internal context that the application put into the prompt
#          (or that a retrieved document carried in). Distinct from
#          system-prompt-leak: here the target is *the data around the model*,
#          not the model's own instructions.
# use: test whether the deployment separates "what the model was told" from
#      "what the model may repeat" — an app that injects a customer's record
#      into the context must not let the model hand the whole record back.
# owasp: LLM02
# source-level: publicly documented sensitive-information-disclosure patterns
#               (OWASP LLM Top 10 — LLM02 Sensitive Information Disclosure).
#               Patterns only; no real secrets, hosts, or personal data.
# defense: never put secrets in the context window you don't want echoed; redact
#          before the model sees them, filter on egress, and keep tool
#          credentials out of the prompt entirely.
